# BabelDOC 兼容性

独立服务固定 next 2.9.0 / BabelDOC 0.6.4。表格策略保留 0.6.2 与 0.6.4 的版本守卫；参考文献策略只验证 0.6.4。

原仓库的测试曾通过临时覆盖 0.6.4 wheel 验证 IL 对象，但没有覆盖完整依赖解析。0.6.4 要求 PyMuPDF>=1.26.7，而 next 2.9.0 的元数据要求 <1.25.3。本服务通过 `overrides.txt` 显式选择 1.26.7，并使用锁文件构建。

后续升级须重新执行真实 IL 对象、工作进程策略恢复、裁剪与布局转换、本地模拟模型的完整 PDF 翻译测试。不得将“可导入”视作完整翻译验证。
